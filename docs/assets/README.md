# Demo assets

- `demo.mp4` (≈ 1.1 MB) / `demo.gif` (≈ 2.3 MB, 1080 px, 6 fps, ffmpeg two-pass palette with 128 colours, `stats_mode=full`, no dithering, `diff_mode=rectangle`; Phase 47 re-encoded it from the Phase 25r 3.7 MB GIF, 1200 px / 12 fps, to stay well under the README media cap; a `stats_mode=diff` palette lost the green accents): a 30 s simulated call on the "Easy deal" scenario, shown at the top of the root README. It opens in the Debt negotiator view, plays the call with **Watch a call**, opens one row of "How the agent decided" (the 31% counteroffer), shows the drafted agreement and payment schedule at the top of the right column, and ends on the Creditor rep view. Recorded 2026-10-08 (Phase 25r) from a local server (`LLM_PROFILE=offline`, so no model call) with a headless Chrome screencast at 1440×900 in the light theme. The autoplay pause was raised from the console's 1.2 s to 2.6 s per step (`autoplay_pause_ms` in the start message) so each step can be read; the call itself is unchanged (6 turns, deal at 40%).
- `console-operator-autoplay.jpg`: the Debt negotiator view after the same simulated call, with the 31% counteroffer row open (Phase 25r).
- `console-creditor-autoplay.jpg`: the Creditor rep view (`?view=rep`) after the same simulated call (Phase 25r). It replaces `console-creditor-live.jpg`, which showed the older UI.
